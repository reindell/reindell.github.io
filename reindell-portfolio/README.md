# Reindell Almazan — Developer Portfolio

A responsive, accessible, dependency-free portfolio for [Reindell M. Almazan](https://github.com/reindell), featuring public-safe summaries of full-stack work, academic research, and design projects.

## Preview locally

Open `index.html` in your browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Open [Settings → Pages](https://github.com/reindell/My-own-website/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then **Save**.
4. Once GitHub finishes publishing, visit `https://reindell.github.io/My-own-website/`.

There is no build process. Edits pushed to `main` will be republished automatically once Pages is configured.

## Files

- `index.html` — content, metadata, project cards and accessible dialogs
- `assets/styles.css` — responsive styles and visual mockups
- `assets/script.js` — project filtering, accessible dialog and mobile menu
- `assets/favicon.svg` — vector favicon
- `robots.txt` and `sitemap.xml` — indexing hints for the GitHub Pages URL

## Privacy / project representation

The manufacturing project is described only at a high level. No employer assets, internal screenshots, credentials, company network addresses, operational metrics, or proprietary source code are included. The AI accessibility project is explicitly identified as a **research concept**, not a deployed product. Academic exercises and design projects are identified as such. The UI mockups are decorative, conceptual illustrations and do not depict confidential software screens.

This portfolio links to the owner's GitHub profile. Add repository-specific or demo URLs only after the individual projects have been cleared for public sharing.

## Customization

Edit the About section and project cards in `index.html`. Update corresponding notes in the `projects` object in `assets/script.js`. Colors and components are defined with CSS variables in `assets/styles.css`. Avoid publishing personal contact details without explicit intent.
